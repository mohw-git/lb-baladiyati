# Baladiyati mobile branding assets

Place official municipal photography here. The app uses structured placeholders until files exist.

| File | Usage |
|------|--------|
| `auth-bg-saida-waterfront.png` | Welcome, login, register — navy overlay, subtle background |
| `home-bg-lebanon-coast.png` | Citizen home hero — low opacity behind greeting |
| `worker-bg-municipal-work.png` | Worker dashboard header and field empty states |
| `announcement-saida-waterfront.png` | News / municipality notice cards |

After adding a file, uncomment the matching `require()` in `lib/branding/assets.ts`.

Recommended: landscape or wide crops, 1200px+ width, compressed JPEG/PNG, civic/public-service tone (no heavy filters).
